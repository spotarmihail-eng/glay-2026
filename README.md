# GLAY 2026

Сайт премии сообщества GLAY 2026. Статическая версия для GitHub Pages.

## Что уже есть
- Адаптивный тёмный дизайн с лаймовыми акцентами.
- 32 участника и Twitch-ссылки; Telegram-ссылки указаны только там, где их предоставили.
- 17 номинаций с исходным написанием.
- Поиск по участникам.
- Мобильная навигация.

## Публикация на GitHub Pages
1. Открой Settings → Pages в репозитории.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Выбери ветку main и папку /(root), затем Save.
4. Сайт будет доступен по адресу https://spotarmihail-eng.github.io/glay-2026/.

## Discord и голосование
В config.js пока нет Client ID — его можно указать после настройки OAuth2. Не публикуй Discord Client Secret или токен бота в репозитории.

Важно: GitHub Pages — статический хостинг. Для настоящей Discord-регистрации, проверки одного голоса на пользователя, сохранения и отмены голосов потребуется серверная часть с базой данных. В текущей версии голосование показано как готовящийся раздел и не принимает реальные голоса.
